1. Scope & Objective

FSKU is an open-source compute market benchmark engine designed to provide transparent, reproducible, SKU-specific reference indices and forward term structures for enterprise GPU compute without relying on black-box proprietary methodologies.

2. Unit Normalization

Because cloud infrastructure providers sell compute across heterogeneous configurations (e.g. single-GPU instances, 8-GPU HGX chassis, multi-node clusters), server-level pricing is mathematically normalized to a single comparable unit:

Normalized Rate ($/GPU-hour) = Published Hourly Server Price ÷ Published GPU Count

No arbitrary adjustment factors are applied for CPU, system RAM, local NVMe storage, commitment terms, egress fees, or power utilization. "Normalized" explicitly denotes unit-comparable rate discovery.

3. Index Aggregation Methodologies

  • Robust Median (Default): Selected for benchmark robustness against extreme upper-tail retail price quotes.
  • 10% / 20% Trimmed Mean: Symmetrically removes the top and bottom k percent of observations to mitigate single-provider outlier leverage.
  • Provider-Balanced Mean: Computes the median rate within each provider first, then averages across providers to prevent provider quote-count distortion.
  • GPU-Count Weighted Average: Weights quotes by total physical GPUs deployed in the instance configuration.

4. Technological Deflation ($d$) Inference

To eliminate provider pricing markup bias from hardware generational decay, rental price compression is inferred strictly across matched providers offering multiple architecture generations:

Annual Tech Deflation (d) = 1 − (P_older ÷ P_newer)^(12 ÷ Cadence_Months)

Matched generation pairs evaluated include A100 → H100, H100 → H200, H100 → B200, and B200 → B300.

5. Implied Forward Term Structure

Forward curves are model-implied using the cash anchor $S_0$, annual carry & scarcity assumption $c$, and inferred tech deflation $d$:

F(T) = S₀ × [(1 + c) × (1 − d)]ᵀ

where $T$ represents the delivery tenor in years ($T = m / 12$). Forward curves are indicative term structure models, not executed transaction commitments.
